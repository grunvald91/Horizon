# Horizon → Telegram: как это работает

- **05:17 МСК**: workflow «1. Horizon — собрать новости» собирает и сортирует новости за сутки (модель Grok 4.7 через claudehub.fun) и складывает их в очередь (ветка `news-queue`).
- **09:00–21:00 МСК, раз в час**: workflow «2. Telegram — публикация» отправляет следующую порцию **во все чаты, куда добавлен бот**. Новости распределяются по часам поровну, самые сильные выходят утром.

## Куда бот публикует
Бот сам находит чаты, отдельно настраивать ничего не нужно:
- **Канал**: добавь бота **администратором** с правом «Публикация сообщений». Посты выходят от имени канала.
- **Группа**: добавь бота участником. Telegram не позволяет ботам писать в группе от имени чата, поэтому сообщения там будут от бота.
- Чат подхватывается при ближайшем часовом запуске. Если бота удалить или лишить прав, чат сам исчезнет из рассылки.
- Чтобы в канале под постами не было подписи автора, выключи в настройках канала «Подписывать сообщения».

## Секреты (Settings → Secrets and variables → Actions)
| Имя | Значение |
|---|---|
| `ANTHROPIC_API_KEY` | ключ `sk-hub-...` из app.claudehub.fun |
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `TELEGRAM_CHAT_ID` | не обязателен, только если нужен чат, куда бота не добавляли |

Модель по умолчанию `grok-4.7`. Перед каждым сбором скрипт проверяет ключ и модель и в логе показывает доступные ID Grok. Сменить модель можно во вкладке **Variables**: создай переменную `HORIZON_MODEL`.

## Запуск
1. **Actions** → «I understand my workflows, go ahead and enable them».
2. Вручную запусти **1. Horizon — собрать новости** → **Run workflow** (5–20 минут).
3. Добавь бота в канал или группу.
4. Вручную запусти **2. Telegram — публикация**. Если сейчас время с 9 до 21 по МСК, выйдет первая порция.

## Важно
- У бота не должно быть webhook (если токен раньше использовался в другом боте на сервере). Иначе бот не увидит, куда его добавили.
- GitHub может запускать задачи по расписанию с опозданием на 5–30 минут.
- В публичном репозитории расписание отключается после 60 дней без активности. Если посты перестали приходить, открой Actions → workflow → **Enable workflow**.
